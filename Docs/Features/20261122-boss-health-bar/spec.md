## 1. 背景与目标

当前所有敌人共用同一套头顶世界空间血条（`UMALWorldWidgetComponent` + `WBP_EnemyHealthBar`），Boss 和普通敌人在界面上没有区别。玩家与 Boss 交战时，缺少一个稳定、醒目的剩余生命读数，也不容易判断当前是否仍在战斗中。

目标：玩家进入 Boss 的显示半径时，屏幕顶部出现该 Boss 的专属血条，显示名称和受击延迟条；离开半径立即消失；每个玩家独立判断。Boss 死亡后淡出隐藏；首版不显示当前/最大生命数值文本（Owner 决定，后续补）。

## 2. 用户故事

- 作为 **玩家**，我希望进入 Boss 附近时屏幕顶部出现它的血条，离开后立即消失，以便判断当前威胁。
- 作为 **玩家**，我希望受击后主条立即下降、残影条延迟追上，以便感知这一击造成了多少伤害。
- 作为 **开发者**，我希望用敌人种类 tag 决定谁显示 Boss 血条，并能按 Boss 配置显示半径，以便以后新增 Boss 时不用改 UI 判断逻辑。
- 作为 **联机玩家**，我希望每个玩家只在自己的雷达范围内看到 Boss 条，避免远处的队友替我显示无关目标。

## 3. 验收标准

本规格中的定义：

- **Boss**：携带 `MAL.Enemy.Type.Boss` tag 的敌人；种类 tag 不绑定具体蓝图。
- **显示半径**：`DA_CombatConfig.BossBarActivationRadius`，默认 1500 cm，按 Boss 配置；按玩家 Pawn 与 Boss 的平面距离判定。
- **进入/离开半径**：玩家 Pawn 与 Boss 的平面距离 ≤ 半径时，该玩家显示；> 半径时立即隐藏。每个玩家独立判断，不做全局共享。
- **死亡**：Boss 生命降到 0 时血条进入 1.5 秒淡出；Boss actor 被销毁（关卡卸载/控制台销毁）时直接移除，不要求淡出。

表现约定：屏幕顶部居中，左右留安全边距；多条按进入半径的先后从上到下排列，首版最多 3 条，超过时只保留最近进入半径的 3 个；不遮挡现有 HUD 的血条、技能条和菜单入口。首版显示名称、主条和残影条，不显示当前/最大生命数值文本（后续补）。

## 4. 非目标（至少 3 条）

- 本次不做：Boss 阶段、韧性/破防、护盾、技能预警、状态图标。
- 本次不做：Boss 条的当前/最大生命数值文本；后续单独补。
- 本次不做：普通敌人的顶部血条；普通敌人继续用现有头顶血条。
- 本次不做：超过 3 个 Boss 的滚动、折叠、团队框架。
- 本次不做：新的美术风格、动画、音效；首版复用现有 UI 材质与字体。
- 本次不做：存档/重生后的血条持久化；血条只表现当前半径。
- 本次不做：首次受伤触发、8 秒脱战计时；v2 起由半径判定替代。
- 本次不做：Boss 选招、伤害结算、锁定逻辑的改动。

## 6. 风险与未知

| # | 风险 / 未知 | 应对 |
| --- | --- | --- |
| 1 | 未受击的 Boss 也要参与半径检测，如何发现全部 Boss | `AMALEnemyCharacter::BeginPlay` 在服务器把带 Boss tag 的自身注册到 `UMALCombatEventsSubsystem`；销毁时注销 |
| 2 | 敌人种类 tag 与显示半径放在哪里 | tag 用 `AMALEnemyCharacter.EnemyTypeTag`；半径用 `DA_CombatConfig.BossBarActivationRadius`，默认 1500 cm |
| 3 | 每个玩家独立可见性怎么同步 | 服务器每 0.1s 按 PC 的 Pawn 与每个 Boss 的平面距离更新可见集合；只给该 PC 发 `ClientAddBossBar` / `ClientRemoveBossBar`，不广播给全部客户端 |
| 4 | Boss 名称来源与本地化 | 沿用 `DA_CombatConfig.BossDisplayName`；当前为 `Hammer` |
| 5 | 多 Boss 叠放是否遮挡现有 HUD | UI 走查 16:9 / 21:9；首版上限 3 条，位置与间距在 WBP 上调 |
| 6 | Boss 头顶血条隐藏方式（禁用组件 / 换 WidgetClass） | 已实现：`AMALEnemyCharacter::BeginPlay` 对 Boss tag 隐藏 `HealthBarWidget` |
| 7 | 中途加入的客户端是否能看到当前半径内的 Boss 条 | PC `BeginPlay` 服务器侧调用 `SyncToController` 发当前可见列表；下一次 0.1s 轮询补差 |

## 7. 开放问题（阻塞开工）

无阻塞开工的开放问题。首版默认值已在上文确认：

- 显示半径默认 1500 cm，按 Boss 配置；
- 每个玩家独立判断，离开半径立即隐藏；
- 同时最多 3 条，按进入半径先后排列；
- Boss 名称必须可配置；
- Boss 存活且带 Boss tag 即参与半径检测，不要求受击/进入战斗；
- 死亡后淡出（默认 1.5 秒），淡出结束后隐藏。
